# ДачаДрим: 3D-каталог домов

Папка готова к размещению на любом статическом хостинге.

```
index.html           просмотрщик (менять не нужно)
catalog.json         список моделей, ссылки на страницы домов, палитры цветов
update-catalog.mjs   обновляет список моделей по содержимому папки models/
models/*.glb         3D-модели (файлы только читаются, просмотрщик их не меняет)
```

## Как добавить, убрать или заменить дом

Имя и размеры берутся из названия файла:

| Название файла | В списке | Характеристики |
|---|---|---|
| `ДС-2 5,5х5 44мм.glb` | ДС-2, 5,5 × 5 м | габариты 5,5 × 5 м, стены 44 мм |
| `6х6 44мм.glb` | 6 × 6 м | габариты 6 × 6 м, стены 44 мм |

Правила названия: размеры через `х` (русская или латинская) или `×`, толщина стен числом с `мм`. Всё остальное в названии считается именем модели.

1. **Добавить:** положите файл в `models/` и запустите `node update-catalog.mjs`. Без Node можно вручную добавить строку в `"models"` файла `catalog.json`.
2. **Убрать:** удалите файл и запустите скрипт (или удалите строку). Чтобы только скрыть: `{ "file": "models/Имя.glb", "hidden": true }`.
3. **Заменить:** загрузите новый файл с тем же названием.
4. **Порядок:** список всегда по алфавиту, новая модель встаёт на своё место сама.

## Кнопка «Подробнее о модели»

Открывает в новой вкладке страницу дома на сайте. Адрес берётся так:

1. Если у модели есть поле `url`, открывается оно:
   `{ "file": "models/ДС-2 5,5х5 44мм.glb", "url": "https://dachadream.by/sadoviydom/tproduct/..." }`
2. Иначе открывается раздел каталога `catalogUrl` из `catalog.json` (сейчас `https://dachadream.by/sadoviydom`).

Чтобы кнопка вела на конкретный дом, добавьте `url` для каждой модели (адрес страницы товара в Tilda). Сейчас он указан только для ДС-2.

## Сравнение, ссылка, линейка

- **Сравнить:** до двух домов рядом в одном масштабе, таблица с габаритами, площадью по габаритам, высотой и стенами. Какой дом заменить, выбирается кнопками «Дом 1 / Дом 2» над списком.
- **Поделиться:** окно со ссылкой на текущий вариант (дом или пара домов, цвета, окружение, день или ночь, крыша). Ссылка ведёт на страницу, где открыт просмотрщик. Если он встроен в Tilda, укажите в `catalog.json` поле `"shareUrl"` с адресом страницы просмотрщика.
- **Линейка:** показывает длину, ширину и высоту дома по модели, а касание двух точек на доме измеряет расстояние между ними (точки липнут к углам). Размеры считаются по геометрии GLB и включают террасу, поэтому могут отличаться от размеров в названии файла.

## Цвета

По умолчанию стены, кровля и рамы одного цвета: светлое дерево. Красятся три части: стены (вместе с террасой), кровля, рамы. Палитры меняются в разделе `colors` файла `catalog.json`.

## Требования к GLB

Файлы не редактируются, просмотрщик берёт их как есть:

- 1 единица = 1 метр, низ дома на высоте 0 (иначе AR и линейка покажут неверный масштаб);
- группы с именами `walls`, `floor`, `roof`, а также `terrace`, `deck`, `slab`, если они есть;
- стекло: материал с прозрачностью; фундамент: тёмно-коричневый; ручки: тёмный металл;
- сжатие Draco и meshopt не поддерживаются, сохраняйте GLB без них.

## Размещение на сайте (Tilda)

1. Загрузите папку на хостинг (Netlify, GitHub Pages, Yandex Object Storage со статическим сайтом). Нужен HTTPS.
2. Если модели лежат на другом домене, включите CORS для `*.glb` и `catalog.json`.
3. В Tilda добавьте блок T123 (HTML) и вставьте:
   ```html
   <iframe src="https://ВАШ-ХОСТ/index.html?house=ДС-2&tabs=0"
           style="width:100%;height:640px;border:0" loading="lazy"
           allow="xr-spatial-tracking; fullscreen"></iframe>
   ```

Параметры адреса: `house` (имя модели или название файла), `compare=1` и `house2` (режим сравнения), `env` (`plot`, `lake`, `village`), `night=1`, `noroof=1`, цвета `wall`, `roof`, `frame` (id из catalog.json), `tabs=0` (скрыть список моделей), `panel=0` (скрыть всю панель), `share=` (адрес для кнопки «Поделиться»), `catalog=` (адрес другого catalog.json).

## AR

Кнопка «AR-примерка» появляется только там, где браузер поддерживает WebXR (Chrome на Android, нужен ARCore). На iPhone кнопки нет, нужен отдельный шаг через USDZ. AR проверен только в коде, на реальном телефоне не запускался.

## Про защиту

В интерфейсе нет скачивания и редактирования, но браузер всё равно загружает GLB с сервера. Полностью скрыть файлы нельзя.
